# Portfolio — Alina Hnidko

UI/UX designer portfolio, themed as a cinema. Built with Vite (plain HTML/CSS/JS), deployed on Vercel.

Site plan: [docs/Portfolio_Website_Plan_Draft.md](docs/Portfolio_Website_Plan_Draft.md)

```

npm run dev
```
